# Published chapter vocabulary

`GET /api/v1/public/editions/{slug}/chapters/{sequence}/vocabulary/`
requires an already published, public edition and an existing chapter; otherwise
404. It never queues work, runs NLP or calls a provider.

The response contains `chapterId`, `chapterSequence`, `language`, `status`,
`selection`, `words` and nullable `provenance`. Status is `ready`, `pending`,
`stale` or `unavailable`; only `ready` may contain words, and a ready list may be
empty. This is a curated subset of the book's up-to-50 useful words occurring in
this chapter, **not all chapter vocabulary** and not a CEFR word list.

Each word has `lemma`, the attested `surface`, a bounded source `context`,
`blockId`, Unicode-code-point `start`/`end` offsets and `frequencyBand`.
The surface must exactly match that range in the requested chapter's current
block. The context is taken from that block, not generated by AI. An inflected
surface may differ from its dictionary lemma.

`lexical-v3` / schema 2 retains one model-derived example per lemma per chapter
while the **existing lexical pass** processes the text. Selection/scoring remain
unchanged. No extra tokenizer, NLP pass or AI vocabulary extraction is introduced.
Fallback/surface-only lemmas are excluded from chapter examples. Old artifacts
remain history; rerun the existing lexical stage to populate the new shape.

Provenance exposes input hash, processor version and spaCy model/version. The
input hash covers source SHA, ordered chapter/block/text identity, language,
runtime signature and lexical version. Publication reads require matching current
artifacts from a successful lexical run, the configured model, and a lemmatizing
pipeline (or the model tokenizer for Japanese). Missing/blank pipelines do not
silently produce public vocabulary. This deterministic stage has no model prompt.

Text, source, language or chapter-placement changes invalidate the projection.
No editorial level, fidelity warning or publication status is changed by refresh.
