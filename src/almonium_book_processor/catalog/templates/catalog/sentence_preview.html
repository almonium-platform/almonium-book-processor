How alignment works

Blocks pair through the canonical groups both editions inherit, so the paragraphs are already exact. Inside each pair a local multilingual embedding model matches sentences: no paid API is called. Each matched sentence group is then cut at clause punctuation (commas, semicolons, colons, dashes) and the clauses are matched again; a clause pair that is weak, or that resembles a crossing partner nearly as well as its own, is merged back with its neighbour, so a clause moved to the other end of the sentence stays one group. In the paragraph view each group has one tint on both sides; a solid tint is confident, a dashed underline is not. A group the model did not confirm keeps its similarity and is marked for a look; a paragraph it cannot split stays paragraph-aligned. This checks structure, not fidelity: paired passages still need editorial review.
