How alignment works

Blocks pair through the canonical groups both editions inherit, so the paragraphs are already exact. Inside each pair a local multilingual embedding model matches sentences: no paid API is called. Semicolon clauses are refined inside accepted groups. A group the model is unsure of keeps its similarity, and one below {{ low_threshold }}% is marked for a look; a paragraph it cannot split stays paragraph-aligned. This checks structure, not fidelity: paired passages still need editorial review.
